Persona ROAS & Bid-Weighting Model
Install cost, paying subscribers and return by persona

All dollars NZD unless marked USD  ·  CPI range from the E-Road Plan deck benchmarks (USD 3 / 5.29 / 9) converted at NZD per USD  ·  Take rates from Pretian Squared pricing study  ·  Persona parameters other than pool size are planning assumptions to be replaced by P2 test data

How to read this. The model estimates what paid media can buy (installs), how many installs become paying subscribers, and what those subscribers return. At the NZ$3/month Base price, return per subscriber is small, so the model shows which personas clear a 3-year gross-margin payback at which CPI, and weights bids and budget accordingly. It is a planning model: confidence index values are illustrative, not statistical probabilities.

Confidence index = logistic(3 x (3-yr gross-margin ROAS - hurdle)), clipped 5%-95%. It is a directional index, not a statistical probability.
